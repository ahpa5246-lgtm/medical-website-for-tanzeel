Pexels permits free commercial site use, but photos cannot imply endorsement by depicted persons. This implementation labels the images as stock/editorial and does not connect photo subjects with real doctor accounts. If verified provider profiles are released, those must use consented, account-specific images instead of these demo photos.

Image sizes are constrained; checked-in copies are used rather than hot-linking third-party images. No Figma community assets are copied.
